# Assignment 3 — Number Logic and Character Handling

## Overview
This assignment focuses on number-based logic and character processing. It introduces factor calculation, even-number sequences, character-case conversion, and vowel checking.

## Programs Included

| File | Problem | Concepts Practised |
|---|---|---|
| `program3_1.c` | Print the first N even numbers | `for` loop, counter increments, input validation |
| `program3_2.c` | Display the factors of a number other than the number itself | Modulus operator, factor logic, loops |
| `program3_3.c` | Display the even factors of a number | Multiple conditions, `&&`, factor logic |
| `program3_4.c` | Convert an alphabetic character to the opposite case | `char`, ASCII character values, conditions |
| `program3_5.c` | Check whether a character is a vowel | Character comparison, case normalization, `BOOL`, `TRUE`, `FALSE` |

## How to Compile and Run

You need a C compiler such as GCC. Open a terminal in this folder and compile one program:

```bash
gcc program3_1.c -o program3_1
```

Run it:

- **Windows:** `.\program3_1.exe`
- **Linux/macOS:** `./program3_1`

Replace the source and executable names to run another program.

## Key Learning Outcomes
- Generate number sequences using loops.
- Identify factors using the modulus operator.
- Combine conditions with the logical AND operator (`&&`).
- Work with character variables and character ranges.
- Convert uppercase and lowercase English letters.
- Write a function that returns a Boolean-style result.

## Placement Preparation
These exercises are useful for practising beginner-level coding questions on:
- Even-number sequences
- Factors and divisibility
- Logical operators
- ASCII-based character operations
- Vowel checks and case-insensitive logic
- Boundary conditions and loop limits

**Practice tip:** For factor programs, test a prime number, a composite number, and `1`. For character programs, test uppercase and lowercase vowels, consonants, and a non-alphabetic character.
